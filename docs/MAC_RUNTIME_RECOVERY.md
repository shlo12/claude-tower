# 普通 Mac 运行中恢复期（2.24.0 / Shield 1.14.0）

仅适用于本地代理客户端的已准入会话。单次 HTTPS 传输或边缘出口查询失败，且快照不超过 45 秒、系统代理与 TUN 在位、控制 API 确认全局及原节点、DNS 与 UDP 检查均通过时，显示黄色提醒、保留原绑定，并自动强制刷新探测。连续 120 秒未恢复则结束会话。新启动没有宽限。

普通 Mac 没有 VM 独立 pf 保证，因此不宽限 DNS/UDP 证据缺失、过期快照、代理或 TUN 丢失、节点变化、已知实际出口变化、直连或证书错误。上游代理模式仍使用原有严格判据。保护只能基于采样，恢复期不代表逐包审计或零泄漏保证。

源代码与 VM 共用，但 VM 保持自己的受管理固定链路判据。此次普通 Mac 安装包不包含 vm-profile.json，不会把普通宿主误识别为受管理虚拟机。VM 已安装的 2.23.3 未被此宿主安装操作替换。
