# 宿主小工具：傳入虛擬機

雙擊 `傳入虛擬機.app`，確認目標是已啟動的 macOS 虛擬機，將檔案拖入視窗中的拖放框，放開後即可傳送；也可以按「選擇檔案並傳送…」。收件位置是**客機** `~/Downloads/VM-Inbox`，每批使用獨立資料夾。在客機 Finder 按 `⇧⌘G`，輸入上述位置即可查看。

## 使用條件

- 宿主 macOS 11 或更新版本，已安裝且授權可使用 `prlctl` 的 Parallels Desktop；支援 Intel 與 Apple Silicon。
- 客機已啟動並登入普通使用者的 macOS 桌面，Parallels Tools 通道可用，且存在 `/usr/bin/python3`。此專案目前的 macOS 虛擬機已具備這些條件。
- 每批 1–100 個普通檔案，單檔最多 2 GiB、每批合計最多 8 GiB。資料夾請先壓縮為 ZIP；工具不自動解壓。符號連結與特殊檔案不接受，同批重名請分開傳送。
- 應用採 ad-hoc 簽名，沒有 Apple Developer 公證；新下載或跨機器使用時可能出現 macOS 安全提示。本工具不修改 Gatekeeper 設定。

## 傳送流程與範圍

1. 宿主只讀取使用者選中的普通檔案，以 Parallels `exec` 的 stdin 傳入客機。不開啟 Parallels 的共享資料夾、剪貼簿或跨系統拖放，也不開啟 SMB、SSH 或新的網路埠，不修改 pf、代理或 Shield。
2. 客機接收程式先降權至當前登入使用者，再建立私有暫存批次；資料夾權限 700、檔案權限 600。檔案不自動執行或開啟。
3. 每檔核對長度與 SHA256；所有檔案通過，且宿主送出整批完成訊號後，才把整批移到正式收件位置。不覆蓋先前批次。
4. 一般取消或校驗失敗會清除本批暫存；傳輸通道意外中斷時，客機接收程式會在最多約 60 秒未收到資料後清理。若客機停電、崩潰或接收程式被強制殺死，可能留下收件夾內的隱藏 `.incoming-*` 目錄。取消若發生在最後提交之後，檔案可能已收妥，以客機收件夾為準。

不重建宿主絕對路徑、擁有者、群組、ACL、擴充屬性、資源分支、執行權限或原修改時間。接收檔案使用新建時間與客機使用者身分；工具不寫內容日誌、選檔歷史或常駐服務。傳輸期間的檔名、大小與雜湊仍會由雙方接收程序處理。

## 檔案內容的邊界

**保留檔名與完整檔案內容。** EXIF、Office 作者、PDF 屬性、壓縮包內路徑、程式碼註解和檔案內的帳密等，屬於檔案內容，工具不會自動清洗。ZIP 內的符號連結或原始屬性也不會因外層傳送而消失；客機解壓時需自行注意。

本工具縮小日常共享範圍，不能保證抹除全部宿主關聯，也不是防惡意客機或已被控制的 Parallels Tools 的安全邊界。接收元件與工具使用既有虛擬化維護通道；不宣稱該通道是硬體強制單向或端到端加密。

## 開發與驗證

來源：`tools/vm-transfer/VMTransfer.swift`、`tools/vm-transfer/receiver.py`、`tools/vm-transfer/audit.py`。無額外第三方套件；Swift 使用系統 Cocoa/CryptoKit，客機 Python 接收端只用標準函式庫。

構建：`sh tools/build-vm-transfer.sh`。產物在 `dist/vm/傳入虛擬機.app` 與 `dist/vm/VM-Transfer-1.2.0-macos.zip`；不會自動安裝到宿主或客機 Applications。

隔離測試：`python3 tools/test_vm_transfer.py`。實機驗證應使用無敏感內容的測試檔，核對完整性、客機擁有者及權限、附加屬性、取消和普通中斷後的清理。

## 1.1.0：傳輸結束核驗與閒置巡檢

每次傳輸使用隨機會話標記。正常完成、取消或啟動後失敗，工具都會等候宿主傳輸程序結束，再發起一次短暫、唯讀的客機程序核對，確認客機沒有本工具帶標記的接收程序；核對請求本身也要退出。只有宿主與客機兩項都核對成功且數量為零，介面才顯示綠色「本工具傳輸已結束」。

收件成功與結束核驗分開顯示：即使檔案 SHA256 正確，若核驗失敗、客機不可達或仍有接收程序，會顯示橙色待確認，暫停下一次傳送。按「核對結束狀態」可以重新查詢；不自動重傳已收妥的檔案。核驗為唯讀操作，遇到維護通道的瞬態錯誤最多重試一次。

小工具啟動並選定目標後會先核對一次。視窗開啟、沒有傳送或核對時，每 10 秒只在宿主本地巡檢帶本工具標記的傳輸程序，不週期性登入客機。閒置時若發現這類程序或巡檢失敗，會改為警告並要求重新核對；不自行殺死其他工具實例的傳輸。關閉工具後沒有新增常駐監測服務。

核驗結果帶有時間，只代表當時所見。這不是對整個 Parallels 維護能力的封鎖：不覆蓋其他應用或未帶標記的舊版接收端，也不能保證偵測到被惡意程序隱藏、偽裝或完全在客機內重新建立的通道。宿主閒置巡檢只涵蓋當前宿主使用者的本工具傳輸程序。

## 1.2.0：宿主視窗拖入檔案

可從宿主 Finder 將一個或多個普通檔案拖到工具內的拖放框。可接收時會高亮，放開後即使用上方選定的虛擬機傳送；原始檔案保留。下方選檔按鈕與鍵盤操作仍可使用。

這是宿主應用內的檔案輸入，不是把檔案直接拖到虛擬機桌面，不需要開啟 Parallels 跨系統拖放。拖入後共用原有的傳輸、SHA256、取消與雙端結束核驗流程。

傳送中、核驗中、選檔視窗開啟或結束狀態未確認時，不接受新批次。資料夾、符號連結、網頁連結、文字及檔案承諾（尚未落地的郵件附件等）不接受；資料夾先壓縮為 ZIP，附件先存到本機。混合有效與無效項目時整批拒絕，不會只傳其中一部分。
