# 菜单栏与维护工具

**日常从菜单栏查看检测与守护状态，维护工具和魔塔按需打开。**

## 统一面板

macOS 日常启动后只在菜单栏运行，点击盾牌图标弹出既有风格的 **Shield 哨兵面板**：保留绿色勾号、黄色提醒、灰色未确认，以及瞭望金色选中态和戒严红盾。指标按 **网络接管 / 出口与泄露 / 本机环境 / 值守与更新** 分类，可以展开；未确认不会计为通过。不创建独立的日常窗口，不显示 Dock 图标。面板使用原生哨兵直接推送的状态。

日常打开不启动 Python 诊断引擎。需要维修时点“全部工具”，在同一个菜单栏面板内按分类选择单个工具；DNS／UDP 的“查看处理”直接进入对应子页。不会打开旧的大工具窗口或双层导航。点击“返回哨兵”释放按需启动的工具引擎；系统授权框临时收起面板时保留上下文，避免打断已确认的写入。魔塔从顶栏“打开魔塔”进入主窗口，进度与战绩保留。

点击面板外收起弹出面板，后台继续值守；退出保护会先结束戒严会话，Claude 未能退出时继续值守。戒严使用期间先结束会话，再调整网络或修复设置。

产品名已从 Claude Tower / Claude Shield 改为 CC Tower / CC Shield；Bundle ID（`com.ccclean.*`）与 `~/.ccclean` 数据目录不变，窗口显示为 CC Shield。已有魔塔进度、作者战绩、配置及恢复记录沿用。Windows 共用检测界面，但没有 macOS 原生值守与启动准入。

CC Tower 是一款在本机运行的 **Claude 环境体检与维护工具**。它把分散在系统、客户端和代理设置里的检查集中到一个界面：先查看证据，再决定是否处理，处理后重新检查。

你可以用它排查代理是否接管、DNS 与 IPv6 是否符合预期、哪些本地缓存和配置需要整理；也可以在 macOS 上启用 **CC Shield · 哨兵**，在后台持续检查网络状态。

> **它帮助你了解和维护本地环境，不承诺防封、零泄漏或绕过平台限制。** 通关和评分是检测结果的呈现方式，不是账号安全认证。本项目由 **shlo** 维护，是独立项目，非 Anthropic 官方产品。
