Bundled Python retains LICENSE.txt: PSF v2, historical BeOpen/CNRI/CWI terms, and Zero-Clause BSD terms for documentation examples. Windows Python also includes Microsoft redistributable conditions and component notices including bzip2, libffi and Apache 2.0 text. These notices are third-party licensing information, not project-author signatures. Do not remove or replace them with shlo. This inventory does not certify every transitive dependency license.


Build and development tools: macOS runtime downloads come from astral-sh/python-build-standalone; Windows runtime downloads come from python.org. The optional recording script uses Playwright; the optional Windows EXE build script uses PyInstaller. These tools are not authors of the application business source. The current Windows portable package does not bundle Playwright or PyInstaller. The app also calls third-party IP diagnostic services; calling an API does not establish that its server source is included here.
